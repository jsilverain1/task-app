# Task App — React Native

A full stack task management app built with React Native (Expo) and Spring Boot.

## Features
- User authentication with JWT
- Create, read, update, and delete tasks
- Secure token storage
- Clean, responsive mobile UI

## Tech Stack
- React Native (Expo)
- TypeScript
- Spring Boot (Java)
- PostgreSQL

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Run `npx expo start`ur open source platform and contribute.
