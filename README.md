# Task App — React Native Frontend

A full stack task management mobile app built with React Native (Expo) and TypeScript. 
Features JWT authentication, real-time task management, and a clean intuitive UI.

## Features
- User registration and login with JWT authentication
- Create, read, update, and delete tasks
- Toggle task completion
- Secure token storage using device encryption
- Empty state, loading states, and error handling
- Auto redirect based on authentication status
- Clean, responsive mobile UI

## Tech Stack
- React Native (Expo SDK 54)
- TypeScript
- Expo Router (file-based navigation)
- Expo SecureStore (encrypted token storage)
